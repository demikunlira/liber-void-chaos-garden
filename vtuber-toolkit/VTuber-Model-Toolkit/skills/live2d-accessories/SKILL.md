# Live2D accessories

Ask which props, placement, motion, outfits and toggle behavior the user wants. Inspect the current project and preserve editable sources and a backup. Use supplied art when available; crop and clean its alpha without removing intentional colors. Plan layer ownership, occlusion and motion space: attach held objects to the appropriate arm or hand, keep floor props anchored appropriately, and animate floating objects independently with a smooth loop if requested.

Create distinct expressions or parameters and controller actions as supported by the actual target runtime. Preserve unrelated pose, outfit and effect states. Test requested pose and outfit combinations, draw order, clipping, visibility, transitions and actual playback. Show previews and incorporate human feedback on placement, seams and animation. Deliver versioned editable and runtime assets plus dependencies, checks and limitations.
