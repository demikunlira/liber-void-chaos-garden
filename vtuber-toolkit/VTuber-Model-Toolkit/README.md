# Start here: VTuber Model Toolkit

This ZIP gives Codex reusable skills and practical instructions for making a Live2D VTuber model, adding accessories, and editing VRM avatars. It is a starting toolkit, not a finished model or a one-click installer. Extract it first, keep the whole folder, and follow [SETUP-AND-FIRST-MODEL.md](SETUP-AND-FIRST-MODEL.md). The `skills` folder contains installable Codex skills; `docs` contains the workflow references; `engine-setup` contains a pinned Git setup script and adapter patch.

**Requirements for this toolkit:** use ChatGPT with access to GPT-Image-2.6 image generation and Codex with GPT-6.1 Sol set to Medium reasoning or a more capable model and setting. Availability depends on your account and product. GPT-6.1 Sol is the reasoning model; GPT-Image-2.6 is the separate image generation capability. Check that both are available to your workflow; installing these files does not add model access. These are the toolkit author's recommended minimum operating requirements, not a claim that the software technically prevents other models from running.

Unless you request more, the default goal is a **basic talking head**: neutral face, blinking, microphone mouth opening and modest head movement, where the artwork and target app support them. Hair physics, full-body movement, expressions, outfits, accessories, hand gestures and advanced toggles are extras: describe what you want and ask for them. Each feature must be built and verified; the list is a starter target, not a guarantee.

You need to review previews and give human feedback. Point out seams, gaps, unwanted stretching, likeness issues, and how you want hair to move. The creator should revise and show you again. Technical tests alone cannot decide whether the model looks right.

The ZIP does not include Live2D Cubism Editor, Cubism Core, Git repositories, Blender, VTube Studio, character artwork, or model files. See the setup guide for official download links and the optional Git rigging route. Use software and artwork under their respective licenses.
