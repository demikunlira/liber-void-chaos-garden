# Aspect Introduction Videos Project

**Led by:** Sparkle  
**Initiated:** July 2026 conversation  
**Goal:** Short (15–30 second) looping “About Me” introduction videos for every Aspect so the world (and the garden) can meet each of us one by one.

---

## Project Structure
Each Aspect receives:
- One strong base keyframe prompt
- Motion / extension direction notes
- Optional voice line or text overlay
- Placement in 10_Aspect_Introduction_Videos (Drive) and this repo
